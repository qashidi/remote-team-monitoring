
# Remote Team Monitoring - Divisi Keuangan

Aplikasi dashboard monitoring tim remote untuk divisi Keuangan.

## Cara Menjalankan di Lokal
```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Deploy ke Streamlit Cloud
1. Fork atau upload repo ini ke GitHub.
2. Buka [Streamlit Cloud](https://streamlit.io/cloud) dan pilih repo ini.
3. Jalankan aplikasinya.
